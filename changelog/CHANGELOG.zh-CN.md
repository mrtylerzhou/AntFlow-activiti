# 更新日志 / Changelog

本文档记录 AntFlow 各版本的变更内容。

---

## [2.1.0] - 2026-08-22

基于 commit `9ecb7a0feb5446c80d1b3111bf0b0feb428b174c` 之后的所有变更整理，版本号已升级至 **2.1.0**。

### ✨ 新功能
- **流程分类配置**：支持对流程进行分类管理。
- **APP 管理**：新增移动端 APP 管理模块，修复 APP 版本字段与 MySQL 冲突、版本无法切换等问题。
- **数据库管理 CRUD**：新增数据库管理相关的增删改查接口。
- **流程权限管理**：新增流程权限管理功能。
- **部门管理接口**：新增部门管理相关接口及部门树优化。
- **流程人员/部门/角色管理界面**：新增可视化配置界面。
- **业务数据查看**：新增业务数据查看功能，并优化业务数据展示。
- **发起页流程项**：新增发起页流程入口配置。
- **节点防撤回**：新增节点防撤回能力。
- **标签选审批人**：支持根据标签选择审批人。
- **节点加签**：新增节点加签功能（支持自动节点回显）。
- **驳回/退回改进**：
  - 优化流程驳回逻辑，被驳回的流程不允许再次点击驳回。
  - 不同意见时可选择结束流程或退回到指定节点。
  - 优化层级加签节点的加签处理。
- **批量审批**：新增批量审批功能，并优化相关代码与审批列表 Y 轴滚动条。
- **自动审批设置**：新增允许用户配置自动审批设置的能力。

### 🐛 Bug 修复
- 修复日期范围解析失败的 bug。
- 修复类型关系判断错误导致外部流程没有通知的 bug。
- 修复流程有加签时，打回任意节点从头开始流程断线的问题。
- 修复表单中的人员报错 bug。
- 修复流程模板表新增字段带空值导致的报错 bug。
- 修复层级加签节点加签不生效的 bug。
- 修复加签节点按钮权限问题（改为从父节点继承）。

### 🔧 优化与重构
- 优化 bpmnconf 获取逻辑。
- 优化部门 demo 数据重新生成与权限列表查询。
- 移除 starter 模块过期代码 / 过时依赖。
- 恢复流程审批功能。
- 调整 `.gitignore`。
- 优化流程驳回体验（被驳回后禁止重复驳回）。
