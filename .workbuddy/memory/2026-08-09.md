## Bug 修复:加批角标不显示(数字数组格式兼容)

**根因**:后端返回的 `buttons.approvalPage` 是**纯数字数组**(mock: `"approvalPage": [3, 4]`),而 nodeWrap 判定用 `some(b => b.buttonType == 19)`(对象格式),数字没有 `.buttonType` → 永远 false → 角标不显示。表单权限 `lfFieldControlVOs` 是对象数组所以正常。流程加载时无统一格式化按钮(已确认),drawer 面板(ButtonStepPanel/ButtonPermDialog)都做了数字兼容,唯独 nodeWrap 渲染层没做。

**修复**:nodeWrap.vue 新增 helper `hasButtonType(btnList, type)`(兼容数字数组 `[3,4,19]` 与对象数组 `[{buttonType:19}]`),并替换 4 处判定:
- `signUpShow`(加批角标 19)
- `hasSignUpButton`(并行分支加批)
- 模板 42 推进图标(`approver-drive-ahead`)
- `titleBgColor` 里 42 推进着色

**经验**:本项目按钮配置类字段(buttons.approvalPage/viewPage/startPage)后端存数字数组、前端面板操作后转对象数组,所有基于 buttonType 的判定必须用 `hasButtonType` 式兼容,勿直接用 `b.buttonType == x`。
