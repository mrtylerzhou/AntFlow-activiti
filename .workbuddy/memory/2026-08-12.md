# 2026-08-12 工作日志

## 审批人非办公状态自动转办(新功能)

**需求**:流程管理-流程类型-设计流程-高级设置 tab 新增「审批人非办公状态自动转办」开关。勾选后,流程中审批人不在办公状态(不可用)时自动转办给指定的人。

**设计决策**(grill-me 澄清):
- 转办目标人由 `AfUserService.checkEmployeeEffective` 返回的 `delegateUser` 提供,门禁不读委托表
- 门禁优先级低于全局委托:全局委托(读 t_user_entrust 按自身时间判断)无条件先执行;门禁仅在其未命中时生效
- 数据源为骨架接口:UserServiceImpl 默认空实现(不查表,恒返回可用),使用方对接考勤/工作日历
- `checkEmployeeEffective` 返回类型 long → UserAvailableVo;原调用点 UserMsgUtils 只取 available 判断(不涉及转办)
- flag = `BpmnConfFlagsEnum.AUTO_DELEGATE_OFF_DUTY(0b1000000000=512)`

**改动文件**:
- antflow-base:新增 `vo/UserAvailableVo.java`;改 `service/AfUserService.java`(返回类型)、`service/UserServiceImpl.java`(空实现)、`constant/enums/BpmnConfFlagsEnum.java`(512 位)
- antflow-engine:改 `bpmnconf/service/processor/NextNodeForwardProcessor.java`(门禁:flag+不可用+时间四象限+delegateUser→转办并写 bpm_flowrun_entrust)、`utils/UserMsgUtils.java`(适配新返回)
- antflow-vue:改 `components/Workflow/AdvancedSetting/index.vue`(新开关卡片,getData 返回完整 extraFlags 叠/清 512 位);`views/workflow/flowDesign/lf.vue` 和 `diy.vue`(publish + dopeSheet 两条链路对 extraFlags 做 OR 合并,避免覆盖 BasicSetting 的位)

**验证**:antflow-base clean compile、antflow-engine compile 均通过;3 个 vue 文件 @vue/compiler-sfc 语法检查通过。
