## 修复:勾选时控制台 vnode.component is null(16:07)
- 现象:勾选"传统风格设计器"checkbox → Uncaught TypeError can't access property "subTree", vnode.component is null
- 根因:el-checkbox 事件链中同步替换大组件树(Process 含大量 Teleport drawer),与 checkbox 自身更新交错触发 Vue 边界 bug
- 修复(flowDesign/lf.vue):
  1. processDesign 容器 `v-if="nodeConfig && activeStep === 'processDesign'"`(基础设置页不挂载画布,勾选时不发生组件树替换)
  2. 两个设计器组件加显式 key
  3. `onTraditionalDesignerChange` 与 `toggleView` 均用 nextTick 延迟提交状态,把组件树切换移出事件链
