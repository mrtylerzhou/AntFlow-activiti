## 五轮: 折叠按钮点击无效果(响应式陷阱)

周老板反馈: "全部展开"/"全部折叠" 按钮点击根本没反应.

**根因:** `groups` 是 `computed`, computed 内 `new Map()` + `Array.from(map.values())` 创建的对象都是**普通对象, 非 reactive**. 直接 `g.expanded = !g.expanded` Vue 不会触发重新渲染.

**修复:**
- 把展开状态从 `group.expanded` 抽离到顶层 `const expandedKeys = ref(new Set())` 记录展开的 taskDefKey;
- `toggleGroup` / `expandAll` / `collapseAll` 都通过 `expandedKeys.value = new Set(...)` 重新赋值触发响应式 (Vue 3 ref 对 Set 的 add/delete 不会自动更新);
- 默认 `watch(groups, ..., { immediate: true })` 在加载时自动展开第一个节点;
- 模板用 `isExpanded(group)` 函数读取, `v-show` 控制表格显隐.

**Vue 3 响应式陷阱教训 (写进 MEMORY):**
- `computed` 返回的数组/对象里的元素是**普通对象**, 直接修改属性不触发更新. 要么把元素包成 `reactive(...)`, 要么把可变状态抽到顶层 `ref`;
- `ref(new Set/Map)` 必须**整体重新赋值** (`xxx.value = new Set(...)`) 才能触发更新, add/delete/clear 不会;
- 想在 computed 内部做副作用初始化 (比如默认展开第一条), 用 `watch(groups, cb, { immediate: true })` 而不是直接写在 computed 里.

周老板反馈: ① 旧值/新值文本带引号; ② 增加"变更人"列(要姓名); ③ 每个节点表格可折叠; ④ `/bpmnAudit/list` 404 重启也不行.
