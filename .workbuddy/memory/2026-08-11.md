# 2026-08-11 工作日志

## antflowcore(.NET) 移植"流程表单字段变更审计"功能

周老板要把 jimuoffice(Java) 的字段变更审计功能移植到 D:\projects\antflowcore(.NET 10 版). 前端共享 antflow-vue, 只做后端.

### 调研结论

- .NET 社区对象 diff 库: CompareNETObjects(6700万下载, 最流行但重且原厂 2024 关闭), Philiprehberger.ObjectDiff(MIT, 属性级 OldValue/NewValue + ToJson, 最贴合审计), AnyDiff/ObjectComparator/ObjectsComparer 等.
- **关键洞察: Java 版实际没真正用 javers 的 diff 能力**(重写后是反射/字典全量字段快照对比, 因为需求是"未变化也记"), 所以 .NET 版选**零第三方依赖方案 A**, 与 Java 版同构.

### .NET 版实现(方案 A, 全部新建/修改)

**新增文件:**
- `AntFlowCore.Base/entity/BpmProcessAudit.cs`: 审计实体(纯 POCO, 无特性; 字段对齐 Java: processNumber/formCode/fieldName/fieldLabel/oldValue/newValue/taskName/taskDefKey/createUser/createUserName/tenantId/createTime).
- `AntFlowCore.Persist.api/interf/repository/IBpmProcessAuditRepository.cs`: `IBaseRepository<BpmProcessAudit>`.
- `AntFlowCore.Persist/repository/FsBpmProcessAuditRepository.cs`: `RepositoryBase` 实现.
- `AntFlowCore.Persist.api/interf/repository/IBpmProcessAuditService.cs`: `SaveChanges(vo, task)` + `GetProcessAudits(processNumber)`.
- `AntFlowCore.Business/service/BpmProcessAuditService.cs`: 核心实现.
- `AntFlowCore.Api/controller/BpmnAuditController.cs`: `[Route("bpmnAudit")]` + `[HttpGet("list")]` → `ResultHelper.Success(...)`.

**修改文件:**
- `FreesqlFluentConfiguration.cs`: ConfigEntity<BpmProcessAudit> → t_bpm_process_audit (FreeSql Fluent 映射, 无特性).
- `ServiceRegistration.cs`: AddSingleton 注册 Service 接口/实现 + Repository 实现.
- `ResubmitProcessService.cs`: 注入 IBpmProcessAuditService; ExecuteTaskCompletion 里 `OnConsentData(vo)` **之前** try-catch 调 `_processAuditService.SaveChanges(vo, task)`.
- `script/bpm_init_db_mysql.sql`: 追加 t_bpm_process_audit 建表 + 2 个索引.

### 实现要点(对齐 Java 版)

- 低代码(`IsLowCodeFlow==1`): 快照 `vo.LfFields`(基类上) + `udlf.LfFieldsMulti`(UDLFApplyVo) → `formAdaptor.OnQueryData(vo)` 拿旧值 → 合并所有 key 逐个记(未变化也记) → 恢复 vo 新值.
- DIY: `CollectDeclaredProperties(vo.GetType())` 逐级 BaseType 反射(排除 BusinessDataVo/Object), 快照/OnQueryData/恢复.
- label: 内联按 `vo.BpmnConfVo?.Id` → `QryFormDataFieldMap(confId)`; 拿不到 confId 时 processNumber → BpmBusinessProcess.Version(bpmn_code) → BpmnConf(form_code+bpmn_code); 外部表单按 formdataId → `QryFieldMapByFormdataId`. 注意 .NET 的 QryFormDataFieldMap **查不到会抛 AFBizException**, 必须 try-catch.
- `ValueToString`: 基本类型(含 DateTime/DateOnly/Guid/TimeSpan)直接 ToString 去引号, 对象/集合才 System.Text.Json 序列化.
- 插入点覆盖 RESUBMIT/AGREE/JP + Assist 委托(与 Java 一致).
