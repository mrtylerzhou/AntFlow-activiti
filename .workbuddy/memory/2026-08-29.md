## grill-me: 移除 getBpmnNodeVoList 的 allHaveJson 兜底（方案已定，未实施）

背景：`BpmnConfBizServiceImpl#getBpmnNodeVoList`(antflow-engine, :1678) 里 `allHaveJson`
判断是否全量走 JSON 配置。早期用关联表、后改为 JSON，第一批 26 张 `t_bpmn_*` 子表已删
（见 doc/tables_to_drop.md）。兜底分支里 4 个 getXxxMap() 有 3 个已经是
`throw new AFBizException("migration error")`。

### 五条决策（周老板拍板）

- **A 空 JSON 行为 → 硬失败**。`getBpmnNodeVoFromJson` 里 `nodeConfig == null` 时
  `throw AFBizException`，与当前兜底行为等价；不静默返回裸 VO。
- **B 删除范围 → 完全无引用才删，有复用就留**。删 5 实体
  (BpmnNodeButtonConf / BpmnNodeSignUpConf / BpmnNodeLabel / BpmnNodeLfFormdataFieldControl /
  BpmnApproveRemind) + 空壳 Service/Mapper (BpmnNodeButtonConfService /
  BpmnNodeLfFormdataFieldControlMapper / BpmnApproveRemind{Mapper,Service,ServiceImpl} /
  BpmNodeLabelsService)。
  **保留**：ButtonPageTypeEnum(ConfigFlowButtonContans/BpmnInsertVariablesImpl 等仍在用)、
  BpmnApproveRemindVo、BpmnTemplateVo、LFFieldControlVO、BpmnNodeLabelVO、
  BpmnNodeButtonConfBaseVo、BpmnConfCommonButtonPropertyVo。
- **C 写路径 → 删 `editBpmnApproveRemind()` 调用(:285)，并给 `BpmnNodeConfigHolder.setTemplateConf`
  补 isInuse 语义**。
- **D 连带死代码 → 全清**：三层未使用的 `conditionsUrl` 参数、NodeLabelsPostProcessor 死局部变量、
  3 处死 import、空接口 BpmNodeLabelsService。
- **E 收尾 → EntityRound20ATest 两个用例必删(编译)，tables_to_drop.md 追加第九批 + 内嵌校验 SQL**。

### 核实过的关键事实（省得下次重查）

- 运行时催办读的是 `t_bpm_variable.variable_config_json`，**从不读 `t_bpmn_approve_remind`**：
  `BpmnInsertVariablesImpl:202` 发布时把 `approveRemindVo` 序列化进变量 JSON；
  `BpmVariableApproveRemindBizServiceImpl:417` 运行时反序列化。`:285` 那次 INSERT 是纯死写。
- DB 版 vs JSON 版语义差异两处：days 来源(join(dayList) vs getDays 原样)、isInuse=false 时
  DB 版清 templateId 而 JSON 版不处理。
- 前端 `antflow-vue/src/utils/antflow/nodeUtils.js:510` 只有 `approveRemindVo: null`，
  Vue3 设计器**没有催办配置 UI**，新流程保存时两条写路径都是 no-op。
- **隐藏 bug**：`NodeLabelsPostProcessor:40` 死代码调用 `SecurityUtils.getLogInEmpName()`
  （非 Safe 版，无登录 ThreadLocal 时抛 `AFBizException("当前用户未登陆!")`），
  产出 `nodeLabels` 却无人使用 → 无登录上下文的保存操作会被它炸掉。
- `getBpmnNodeVoList` 两个调用方：`BpmnConfBizServiceImpl:1486`、
  `BpmnNodeBizServiceImpl:44`（传 null）。该方法**未声明在 `BpmnConfBizService` 接口上**，
  只是 impl 上的 public 方法，改签名不受接口约束。

## 实施完成（同日）

主代码 `mvn compile` EXIT 0；全仓 grep 对 9 个已删符号零残留。共改动 20 个文件
（+111 / -862），删 11 个文件（5 实体 + 6 空壳 Service/Mapper）。

关键实现点：

  approveRemind，days 优先用 `dayList` join（无 dayList 时回退 `getDays()`）。
- `doc/tables_to_drop.md` 新增「八、本次会话清理的实体与死代码」+ 脏数据校验 SQL，
  迁移路线总结补「第九批」。
