# 5 分钟端到端上手

> 从零到跑通第一个工作流只需几分钟。本教程带你走完登录、创建分类、设计流程、发起审批、监控运维的完整链路。

## 第 1 步：登录系统

打开浏览器访问 `http://localhost`，进入登录页。AntFlow 演示环境内置了 20+ 个模拟用户，涵盖不同角色。

输入密码后点击「登 录」即可进入首页仪表盘：

![首页仪表盘](/images/light-1-home.png)

登录后默认进入**首页**，页面展示：
- **统计卡片**：「我的待办」「今日已办」「今日发起」「我的草稿」，实时反映当前用户的流程概况
- **快捷入口**：「流程设计器」「操作手册」「日常开发文档」等
- **版本历史**：页底展示 AntFlow 各版本的发布记录

左侧菜单栏包含五大模块，我们接下来逐一熟悉。

---

## 第 2 步：熟悉流程中心

菜单栏第二项「流程中心」是用户最常用的入口，也是首页默认展示的内容。它聚合展示待办、已办、发起的流程实例。

点击「任务中心」展开子菜单，你会看到：

| 菜单项 | 路径 | 功能 |
|---|---|---|
| 我的发起 | `/flowtask/mytask` | 我发起的全部流程实例 |
| 撤销/退回 | `/flowtask/resubmit` | 被退回或撤销的流程，可修改后重新提交 |
| 待办任务 | `/flowtask/pendding` | 等待我审批的任务 |
| 已办任务 | `/flowtask/approved` | 我已处理过的任务 |
| 抄送到我 | `/flowtask/CopyToMe` | 抄送给我的流程（只读） |

![我的发起列表](/images/light-4-mytask.png)

---

## 第 3 步：创建流程分类

进入 **流程管理 → 流程类型**（`/workflow/flowCategory`）：

![流程类型列表](/images/light-6-flowcategory.png)

点击「新增」按钮，填写：

| 字段 | 说明 | 示例 |
|---|---|---|
| 流程名称 | 如"请假流程"、"报销流程" | 请假申请 |
| 类型标识 | 全局唯一，后端代码通过此标识关联业务表单 | `LEAVE_WMA` |
| 表单类型 | `DIY`（自定义表单）或 `LF`（低代码表单） | DIY |
| 关联表单 | LF 模式关联低代码表单库中的表单；DIY 模式关联前端注册的组件 | — |
| 图标 | Element Plus 图标名 | `timer` |
| 描述 | 流程用途说明 | 公司员工请假审批 |

> **DIY vs LF 选择**：如果你需要**后端写代码**处理业务逻辑和自定义表单，选 DIY；如果你想**零代码拖拽**设计表单和流程，选 LF。

---

## 第 4 步：设计流程

回到 **流程管理 → 流程类型**（`/workflow/flowCategory`），刚刚创建的流程分类已出现在列表中：

![流程类型列表](/images/light-6-flowcategory.png)

点击该分类右侧的「设计流程」按钮，跳转到**流程设计列表**（版本管理页面）：

![流程设计列表](/images/light-7-flowlist.png)

这里展示该流程类型下的**所有版本**。点击某个版本的「设计」按钮，正式进入流程设计器的 **4 步向导**：

### 步骤一：基础设置

配置版本名称和审批人去重规则。

- **去重类型**：`1` = 不去重；`2` = 前向去重（如果当前审批人在前面的节点已经出现过，自动跳过）；`3` = 后向去重
- DIY 流程可勾选「辅助表单」开关，为自定义流程附加一个低代码辅助表单

### 步骤二：表单设计

- **LF 流程**：拖拽控件设计表单（见 [低代码表单设计](/workflow-design/form-design)）
- **DIY 流程**：表单由前端代码实现，此步骤不操作

### 步骤三：流程设计（核心）

可视化拖拽配置审批节点。这是整个流程设计最关键的一步。

从节点树根部的 `+` 按钮，添加以下节点类型：

| 节点类型 | 说明 |
|---|---|
| 审批人 | 普通审批人节点，配置谁可以审批 |
| 条件分支 | 根据条件分发到不同分支 |
| 抄送人 | 只通知不审批 |
| 并行审批 | 多人并行审批 |
| 自动节点 | 满足条件自动通过 |

点击审批人节点 → 配置 **审批人规则**，支持 15 种来源：

- 指定人员、指定角色
- 直属领导、部门负责人
- 层层审批（按级别逐级上批）
- 发起人自选、表单关联
- 自定义规则（UDR）

每个审批人节点还可配置**会签类型**：

| 类型 | 说明 |
|---|---|
| 会签 | 多人全部同意才通过（不限顺序） |
| 或签 | 一人同意即通过 |
| 顺序会签 | 按指定顺序依次审批 |

### 步骤四：高级设置

配置节点级的：
- **操作按钮**：每个审批节点可用的按钮（同意、退回、转办、委托、加签等）
- **通知模板**：触发消息通知的内容模板
- **字段权限**：低代码表单的字段级 R/E/H 控制（Read / Editable / Hidden）

完成后点击「发布」，流程定义即生效。

---

## 第 5 步：发起流程

回到**首页**（流程中心），在仪表盘中可以看到「我的待办」「今日已办」「今日发起」等统计卡片。点击页面中的快捷入口或左侧菜单选择要发起的流程类型：

![首页仪表盘](/images/light-1-home.png)

选择刚刚创建的流程类型，填写表单，点击「提交」。

提交后，在 **任务中心 → 我的发起** 可查看这条已发起的流程：

![我的发起](/images/light-4-mytask.png)

按照设计的审批人规则，流程会自动流转到第一个审批节点的处理人。

---

## 第 6 步：审批任务

切换到审批人账号，进入 **任务中心 → 待办任务**：

![待办任务列表](/images/light-3-todo.png)

点击某个待办任务，进入审批页面。审批页提供完整的操作按钮：

| 按钮 | 说明 |
|---|---|
| 同意 | 通过当前节点，流程流向下一节点 |
| 不同意 | 拒绝当前节点（流程可能结束或跳到指定节点） |
| 退回 | 退回给发起人或任意历史节点 |
| 转办 | 将任务转交他人 |
| 委托 | 自动将任务委托给指定人 |
| 加签 | 在当前节点增加审批人 |
| 加批 | 加签并继续审批 |

每个按钮的可用性由流程设计时配置决定。

审批完成后，可在 **已办任务** 中查看处理历史：

![已办任务列表](/images/light-5-done.png)

---

## 第 7 步：监控与运维

管理员进入 **流程管理 → 流程监控**（`/workflow/instance`）：

![流程监控页面](/images/light-8-monitor.png)

监控页提供全部流程实例的统一视图，支持：
- 按流程类型、状态、时间筛选
- 查看流程详情和流程图
- 每个实例的「更多」菜单提供 9 项高级操作

> 9 项操作的详细说明见 [流程监控高级运维](/ops/monitor-advanced)。

其他运维功能入口：

| 菜单 | 路径 | 功能 |
|---|---|---|
| 委托设置 | `/flowDevops/setting` | 配置自动转交规则（如请假时自动委托） |
| 表单管理 | `/flowDevops/lfForm` | 低代码表单库管理 |
| 消息模板 | `/flowDevops/flowMsgTemp` | 配置通知消息的模板内容 |

![表单管理](/images/light-9-formmgmt.png)

![委托设置](/images/light-10-delegate.png)

![消息模板](/images/light-11-msgtemplate.png)
