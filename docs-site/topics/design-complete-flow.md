# 从零设计一个完整流程

> 理论讲完了，动手吧！本文带你从零开始，用 AntFlow 设计器完成一个包含会签、条件分支、多种审批人来源的完整请假审批流程。全程截图，每一步都有。

## 目标流程

我们要设计的流程：

```
  员工提交请假申请
       │
  ┌────▼────────┐
  │ 直属领导审批  │ ← 发起人的直属领导
  └────┬────────┘
       │
  ┌────▼────────┐
  │ ◇ 条件分支   │ ← 根据天数路由
  └┬───────┬─────┘
  │       │
≥3天?   <3天?
  │       │
┌─▼──┐ ┌─▼──┐
│HR  │ │结束 │
│备案 │ │    │
└─┬──┘ └────┘
  │
┌─▼──┐
│结束 │
└────┘
```

## 第 1 步：创建流程分类

进入 **流程管理 → 流程类型**：

![流程类型列表](/images/topic-flowcategory.png)

点击「新增(DIY)」，填写：

| 字段 | 值 | 说明 |
|------|-----|------|
| 流程名称 | 请假申请 | 显示名 |
| 类型标识 | LEAVE_APPLY | 全局唯一标识 |
| 表单类型 | DIY | 使用自定义表单 |
| 图标 | calendar | Element Plus 图标 |

> 💡 **DIY vs LF**：本例选 DIY（后端写代码处理业务）。如果想用拖拽式表单设计器，选 LF。

## 第 2 步：进入流程设计器

在流程类型列表中，点击刚创建的「请假申请」行右侧的「设计流程」按钮：

![设计器入口](/images/topic-designer-entry.png)

进入 4 步向导界面。

### 向导步骤总览

```
1. 基础设置 → 2. 表单设计 → 3. 流程设计 → 4. 高级设置
```

## 第 3 步：基础设置

第 1 步默认已展示。配置以下信息：

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| 版本名称 | v1.0 初始版 | 方便版本管理 |
| 审批人去重 | 不去重 | 请假流程一般不会重复审批人 |
| 流程说明 | 公司员工请假审批流程 | 给其他管理员看的备注 |

## 第 4 步：表单设计

点击第 2 步「表单设计」。

- **DIY 模式**：表单由前端 Vue 组件实现，在此处选择关联的组件
- **LF 模式**：会打开拖拽式表单设计器

对于 DIY 流程，选择已注册的前端表单组件即可。（表单开发细节参见 [低代码表单引擎](../lowcode/lowcode-form.md)）

## 第 5 步：流程设计（核心）

点击第 3 步「流程设计」进入画布：

![设计器画布](/images/topic-designer-canvas.png)

### 5.1 添加直属领导审批节点

1. 点击发起人和结束之间的 `+` 按钮
2. 选择「审批人」

![添加审批节点](/images/topic-designer-addnode.png)

3. 点击画布上的审批人节点，右侧弹出配置面板
4. 在「审批人设置」tab 中：
   - 选择 **直属领导** 作为审批人来源
   - 会签模式保持默认的 **会签**

### 5.2 添加条件分支

1. 点击审批人节点后的 `+` 按钮
2. 选择「条件分支」

![条件分支](/images/topic-condition-branch.png)

3. 点击「条件1」配置：
   - 添加条件：`请假天数` >= `3`
   - 优先级设为 1

4. 点击「条件2」（默认分支）：
   - 无需配置条件（作为"其他"兜底）

![配置条件规则](/images/topic-condition-config.png)

### 5.3 添加 HR 备案节点

1. 在条件1 的分支上点击 `+`
2. 选择「审批人」
3. 配置审批人来源为 **指定角色** → 选择「HR」角色

### 最终画布效果

完成后画布应类似：

```
[发起人] → [直属领导审批] → ◇(条件:天数>=3?)
                              ├─→ [HR备案] → [结束]
                              └─→ [结束]
```

## 第 6 步：节点高级配置（可选）

选中每个审批人节点，可以进一步配置：

### 按钮权限设置

控制该节点显示哪些操作按钮：

![按钮权限](/images/topic-node-buttons.png)

对于 HR 备案节点，通常只需要「同意」和「不同意」按钮。

### 表单权限设置

控制不同节点能看到/编辑哪些表单字段：

![表单权限](/images/topic-node-formperm.png)

例如：HR 节点只能查看不能编辑请假天数。

### 通知设置

配置审批到达时的消息模板：

![通知设置](/images/topic-node-notice.png)

### 高级设置

为节点添加流程标签：

![高级设置](/images/topic-node-advanced.png)

## 第 7 步：全局高级设置

点击第 4 步「高级设置」：

![全局高级设置](/images/topic-wizard-advanced.png)

推荐开启：
- ✅ **允许撤回**：员工填错信息可以撤回重填
- ✅ **允许转发**：需要抄送给部门秘书时有用
- ❌ **允许作废**：按需开启（作废不可恢复）

## 第 8 步：发布流程

点击右上角「发 布」按钮：

1. 系统校验流程完整性（是否有未配置的节点、断开的连线等）
2. 校验通过后保存为新版本
3. 新版本自动变为"激活"状态，后续发起的流程使用新版本

> ⚠️ 已发起但未完成的旧版本流程不受影响，继续按旧版本运行。

## 第 9 步：测试流程

发布后回到首页，进入 **流程中心**：

![流程中心](/images/topic-taskcenter.png)

找到「请假申请」，点击进入发起页面：

![发起表单](/images/topic-startflow-form.png)

填写表单数据后点击「提交」，流程即开始运行。

### 验证要点

| 测试场景 | 预期结果 |
|---------|---------|
| 请假 1 天 | 直属领导同意后直接结束 |
| 请假 5 天 | 直属领导同意 → HR 备案 → 结束 |
| 直属领导退回 | 回到发起人，可修改后重新提交 |
| 在待办列表查看 | 能看到对应的待办任务 |

![待办任务列表](/images/topic-todo-list.png)

点击待办卡片打开审批详情：

![审批详情](/images/topic-approve-detail.png)

验证三个 tab 都正常显示：
- **表单信息**：看到发起人填写的请假数据
- **审批记录**：历史审批轨迹
- **流程预览**：当前所在位置高亮显示

## 设计模式总结

| 设计决策 | 推荐方案 | 原因 |
|---------|---------|------|
| 审批人来源 | 组织关系型（直属领导/角色） | 不需要维护固定人员名单 |
| 会签模式 | 默认会签 | 单人审批无需特殊配置 |
| 条件使用 | 仅在需要分流时使用 | 不要过度设计 |
| 全局开关 | 开启撤回和转发 | 提升用户体验 |
| 版本策略 | 每次修改发新版 | 保留审计轨迹 |
